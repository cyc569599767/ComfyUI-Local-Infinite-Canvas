# Windows 发布验收说明

产品：Comfy Canvas Desktop 0.1.2
技术栈：Electron 41.0.3 / 内嵌 Node.js 24.14.0
共享画布与网关源码版本标识：v0.24.6（构建包含当前工作区内容，不等同于干净 Git release tag）

## 0.1.2 网关管理修复

- 修复开发版位于 `.build/runtime` 时，Express `sendFile` 将点号祖先目录视为隐藏路径，导致 `/admin` 返回 404 的问题。
- 管理页、生成文件和视频内容均改用固定根目录与相对文件名发送，保留 `dotfiles: deny`，不放开隐藏文件访问。
- 新增真实 HTTP 回归，验证 GET/HEAD 管理页、文件与视频内容返回成功，隐藏文件仍被拒绝。
- 打包测试改为在 `.build` 祖先目录下启动，并严格断言管理页 HTML、渲染元素与工作流 API，不再只记录页面标题。

## 0.1.1 导航调整

- 桌面顶部「无限画布」更名为「无界工作台」。
- 工作台导航在「我的画布」前增加「我的项目」，同时适用于桌面宽屏与移动抽屉导航。
- 新增 `/projects` 项目库入口，复用原有本地项目数据及新建、打开、重命名、导入导出能力，不引入数据迁移或更改原 `/canvas` 路由。
- 中文与英文标签分别为「我的项目」与「My Projects」。

- 0.1.1 打包导航验证：外层「无界工作台」、内层菜单顺序「我的项目 / 我的画布 / 我的资产 / 配置」、`/projects` 点击与深链刷新、项目库打开已保存画布均通过。
- 桌面配置/迁移/生命周期/构建校验测试：36 项通过。
- 共享画布 TypeScript：`tsc --noEmit --incremental false` 通过。
- 网关桌面发行策略及启动器测试：20 通过，1 可选 Electron 路径测试未在该次调用中启用；真实打包验证另外执行。
- 画布从源码构建成功，生产网关依赖按 npm 锁文件安装：73 包。
- runtime 清单验证通过：1,624 个载荷文件，含依赖许可与 SHA-256。

## 尚未作为验收通过的内容

- 未在用户系统实际执行安装/卸载，以免改动其快捷方式、注册表及现有安装；NSIS 生成成功不等同于完整安装交互验收。
- 未使用真实 GPU 提交图像/视频生成，集成测试采用模拟 ComfyUI 接口。
- 未配置代码签名证书；安装包为 NotSigned，可能出现 SmartScreen 提示。
- 未配置自动更新服务。
- 未验证所有第三方节点、模型、剪贴板/权限交互或其他操作系统。
- 部分上游 npm 包未附完整许可文本，依赖声明中明确标注；正式公开发行前应补做法律审查，不把声明清单视为法律授权结论。

## 构建告警

Vite 提示现有画布主 bundle 较大（约 4.4 MB，gzip约1.36 MB），且若干模块同时静态/动态导入。构建和运行测试成功，但后续可做性能拆包。未为消除告警改写用户现有业务代码。

## 升级与数据

安装目录仅承载程序；用户配置、画布缓存、工作流和网关生成结果另存 app userData。安装器默认保留用户数据。工作流仅按文件哈希替换未修改的默认文件，有用户修改的冲突需手动合并，不宣称逐条注册表自动升级。
