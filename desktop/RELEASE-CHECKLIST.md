## 0.1.20 H3 多参无 VDN 节点引用素材丢失修复

- 根因：实际画布的 `video-h3-ref2va-novdn` 节点保存为旧的 `videoMode: text`，前端按 text 过滤了图片/音频/视频，网关实际收不到素材；图片连线本身仍然存在。
- 固定 H3 工作流现在按 workflowId（同时兼容 `-novdn`）决定有效模式：ref2va/character-swap=reference、frames=frames、t2v=text；底模变体同步处理。极速草稿保持用户可配置，不受影响。
- 请求边界再次按工作流归一化，确保图片、音频、视频媒体按多参限制随请求发送；空引用仍严格返回 `missing_reference_media`，不伪造素材。
- 端到端模拟网关验证：同一个 stale-text 的无 VDN 多参节点分别用图片、音频、视频重试，均返回 200、reference 模式、对应媒体数量为 1，保存的 reference 模式和连接刷新后保留。混合媒体也验证通过；没有真实模型推理。
- 18 项前端模式/请求测试、6 项网关 noVDN 媒体验证和 TypeScript 检查通过。完整网关回归 389 项通过。

## 0.1.13 极速草稿真实视频修复

- 替换失配的 T2VA-only FastH3 实验图：原图引用不存在的 LoRA、过期节点参数且缺少首尾帧绑定。改用本地 FL2VA INT8 + Turbo 4 步 v1.2、4B ClipProj streaming 编码器、原生音画解码与 H.264 MP4 输出。此实现不宣称旧 PDMD/VSA 性能或等价性。
- 恢复文生、首帧、尾帧、首尾帧的参数绑定，保持 448 长边草稿用途、24fps 与 17k+5 帧网格；移除前端过期的 PDMD/VSA 请求参数。资源索引与模型扫描同步匹配新图，草稿不再错误要求 TensorRT。
- 网关排除预览和伪装成视频的 PNG/JPEG/GIF/WebP；前端不以进行中任务的 URL 提前判定成功，收到图片时不再静默降级为视频 URL。
- 旧版内置行和图仅在指纹匹配时迁移，原件先保存到用户目录 workflow-backups/0.1.13；自定义图或改动的注册项保留，其他工作流不改。
- RTX 5060 Ti 16GB 实测：文生 66.857 秒、首帧 28.451 秒，均输出 448×256 / H.264 / AAC / 24fps / 107帧 / 4.458秒 MP4；首帧产物 107 个解码帧哈希互异。画布实际点击“极速草稿”再次成功生成视频，播放器推进到 0.786 秒且刷新后可恢复，无播放错误。全程只用中性玩具车测试素材，无真实云端调用。
- 372 项网关测试、133 项桌面测试、TypeScript 检查及打包集成/Agent 验证通过。当前用户目录的精确旧版默认草稿已备份并迁移，其他注册表行逐项比对未变。测试证据和视频位于 desktop/test/artifacts/fast-draft（不打进安装包）。

## 0.1.10 Agent 浮窗与消息操作

- 可拖动对话标题栏移动 Agent 窗口；独立于助手图标保存位置，屏幕缩放/窗口尺寸变化时约束在可见范围内。标题栏按钮、模型选择和输入框不触发拖动；窗口位于图标上层，边缘发送按钮不会被遮挡。
- 用户和 AI 消息均有“重新生成”“删除消息”。重新生成需确认，使用当前模型重发对应用户提示，替换本轮及后续对话；单条删除保留其他聊天消息。二者都不撤销已执行的画布操作，重新生成可能再次调用工具。
- 生成中禁用消息修改，停止后恢复；重新生成清理后续上下文，删除不再保留旧模型上下文，孤立 AI 回复不能错误重试前一问题。保留草稿与聊天持久化。
- 当前会话图片可重用；刷新后历史图片不保存原数据，仅保留附件标记并提示重新附图，不会悄悄转为纯文本重试。
