# Comfy Canvas · 正式桌面工程

**Electron 41.0.3 + 内嵌 Node.js 24.14.0 + 现有 React/TypeScript 画布源码**。

本工程统一构建画布、封装网关生产依赖与本地资源，并生成 Windows x64 安装包。用户安装后**不需要源码仓库、全局 Node.js/npm 或另开画布 Web 服务**。ComfyUI、Python 和大模型由用户单独安装；桌面程序可连接已运行的本机 ComfyUI，或按用户明确选择的目录启动它。

> Electron 界面本身使用 Web 技术，但这里的画布是从源码构建并随程序交付的应用资源，不依赖远端网站部署。

## 开发与构建

需要 Node.js **22.12+**（推荐 24 LTS）、npm、Windows x64。首次准备共享前端依赖：

```powershell
# 仓库根目录
cd infinite-canvas/web
npm ci --legacy-peer-deps
cd ../../desktop
npm ci
npm run build
npm run dev
```

共享画布仍以 [源码目录](<../infinite-canvas/web/src/>) 为唯一来源，不复制两套业务代码。`build` 直接调用 Vite，输出到桌面独占构建目录，**不会覆盖仓库原有画布 dist**；静态资源、生产网关依赖、工作流、节点源码、许可声明均自动纳入。构建期间不运行第三方 npm 安装脚本。构建禁止画布目录存在 `.env*`，避免本机地址、开发插件或凭据进入发行资源。

桌面 0.1.3 同步 Web v0.24.8：新增画布 3D（Idol/MoGe）、风格配方、LoRA 叠层、批量下载及 H3 极速草稿。3D 依赖 ComfyUI 0.44+ 和用户选择安装的可选模型/节点；权重不随桌面包分发。3D 文件 URL 会按本地网关端口解析，避免误请求画布端口。

桌面 0.1.9 的助手统一在 **配置与用户偏好 → 云端 API** 管理 URL、Key、协议及模型；对话窗口只选择已配置模型，不再提供配置或连接测试按钮。支持 Chat Completions、Responses、Gemini 原生、Anthropic Messages、Grok（Chat 兼容；Grok Responses 请选 Responses）。按服务商实际协议配置，不能仅凭模型名称判断；例如 Gemini 原生通常使用 `/v1beta`，兼容 OpenAI 的 Gemini 则选 Chat。支持根地址、版本/自定义前缀和完整端点，拒绝 URL 中夹带 Key。

云端请求由本机网关安全转发，以避免浏览器 CORS；仅提供画布工具与审批，不具备本机代码读写或终端权限。提示词优化也跟随所选协议。新 Key 默认仅当前会话使用，勾选“在本机记住 API Key”后以未加密形式存入本机浏览器/桌面用户数据；原有已保存配置不清除。保留顶部菜单顺序：无界工作台、ComfyUI、服务面板、网关管理。

桌面 0.1.3 对应 Web v0.24.8：包含画布 3D 节点/查看器、风格配方、LoRA 叠层和批量下载；需 ComfyUI 0.44+ 的 3D 插件及模型按需从资源中心安装，大模型权重不随包分发。

| 命令 | 作用 |
| --- | --- |
| `npm run build` | 从画布源码构建，安装锁定网关生产依赖，整理 runtime 和 SHA-256 清单 |
| `npm run dev` | 启动已构建资源；顶部提供开发工具 |
| `npm start` | 正常启动已构建资源 |
| `npm run verify:runtime` | 校验资源清单、路径白名单、版本及依赖闭包 |
| `npm run pack` | 构建并生成 Windows 解包应用目录 |
| `npm run dist:win` | 构建 Windows x64 NSIS 安装包 |
| `npm run test:packaged` | 将打包应用复制到含空格的临时目录，从非仓库 cwd 启动并测试 |

安装包输出到 `release`，文件名为 `ComfyCanvas-<桌面版本>-x64-setup.exe`；解包应用为 `release/win-unpacked/ComfyCanvas.exe`。不要单独复制 EXE，解包分发必须携带整个目录。

开发模式不提供自动热更新。修改共享画布后重新 `npm run build` 并刷新；修改主进程后重启；发布时使用 `dist:win` 从最新源码完整重建。

## 视频完成状态与结果取回

桌面本机连接优先从配置的 ComfyUI `output` 目录读取历史中已经确认完成的文件；限定 output 类型、目录内相对路径并验证真实路径，拒绝穿越和外部符号链接。非本机或文件不在该目录时回退到60秒上限的 HTTP `/view`，headers/body均有硬截止，不再让传输中断长时间挂住生成卡片。

前端状态GET为15秒、暂态失败最多3次；结果下载120秒；本地媒体保存30秒，元数据解析5秒。元数据不可用时保留视频并采用默认尺寸，不阻塞完成；URL回退不再触发第二次无界下载。成功结果清除进度与预览标记，撤销恢复有任务ID的未完成快照会重新查询原任务，不新建生成。

`POST /v1/videos/:id/recover` 只用于失败任务：原 Comfy 历史必须成功、只有一个最终视频且未要求插帧；读取并保存已有结果后标记完成，不重新采样或修改原片。多个输出、失败历史、预览图片及插帧任务均拒绝猜测恢复。

## KVMem / NInfer 本地图片反推

桌面设置可指定外部 KVMem 安装目录、带视觉组件的 `.ninfer` 模型和 GPU 编号；软件与权重不随包分发，也不会自动下载。启用后，本地反推选择器显示 KVMem，旧画布保存的 Qwen/Florence 反推选择自动使用新后端；云端反推和 H3/生图提示词优化不变。关闭开关可恢复原 ComfyUI 反推策略。设置保存后重启桌面生效。

每次反推启动一个随机回环端口、随机认证密钥和模型 ID 的专用 worker，核对身份及视觉能力后只发送本地图片 data URL。完成、失败、取消和正常退出均终止自有 worker 并等待进程关闭；确认退出前不返回 `released: true`。不连接或关闭用户手动启动的 KVMem，也不调用与 KVMem 不兼容的模型 suspend/unload API。每次冷启动较慢，这是换取显存不常驻的取舍。

启动前要求 ComfyUI 队列和桌面待生成队列均空闲；申请卸载 ComfyUI 闲置模型缓存，并核对实际可用显存。本桌面网关在反推/释放期间拒绝新的 ComfyUI 提交，未知提交结果（如超时后可能迟到入队）会阻止启动反推，需确认任务结束再重启网关。直接在外部 ComfyUI 或另一网关提交任务不受此进程内互斥控制，请勿与反推并发。退出 worker 释放其模型上下文，不代表显卡其他程序占用归零；强杀桌面/网关后的孤儿清理尚无 Windows Job Object 保证。

验证包含运行时模拟、真实本机 HTTP 的取消/互斥回归，以及 RTX 5060 Ti 上一张合成图的 RVN 27B 视觉反推：正确识别红方形/蓝圆形，约22秒完成，worker退出后可用显存回升。该小图测试不等于任意高分辨率图片的质量、内存或速度保证。

## Agent 稳定性与素材引用（桌面 0.1.24）

内置助手继续走原生多协议云端模型 → 本机网关 → 画布工具；不强制安装 pi 运行时。修复四项边缘行为：排队请求不再清空后来输入的草稿；待批准画布操作绑定原项目，切换项目或停止后不能误写；流式消息每350ms合并保存，轮次结束及页面离开刷新保存，并提供限1MiB的临时恢复检查点；`@`图片/文本引用发送实际当前内容和nodeId，不再只发标签。

图片上传与引用合计最多6张、序列化素材约30MiB；不存在、不支持或读取期间发生变化的素材会明确报错且保留草稿。图片二进制仍只保留本会话内存，刷新后重生成含图片旧消息需重新提供图片，不能静默猜图。恢复检查点不含API Key或图片预览字节，沿用原有对话存储策略。

验证包括：真实Electron界面文本流、手动批准/拒绝实际文本节点写入、排队草稿、停止、模拟401恢复、跨项目批准拦截、历史与排队时刷新、`@图片`在本地模拟服务端收到图片字节及nodeId。当前选定真实模型另经用户授权短请求验证，文本回复成功；真实服务商工具调用/视觉能力不因此视为验证。`scripts/test-agent-e2e.mjs` 为离线合成测试，不读取个人配置、不调用付费模型。

## 生成前后终端闪窗修复（桌面 0.1.22）

Windows 下网关的 `ffprobe` 媒体信息探测已明确使用 `windowsHide: true`，不通过 shell 执行。桌面托管 ComfyUI 时改由随包的 Python 引导器启动，在该进程内部给普通 `subprocess.Popen` 子进程加 `CREATE_NO_WINDOW`，覆盖节点调用的 ffmpeg 编码、音频合并、图像后处理等辅助命令。它保留 Popen 的类/继承和管道行为，stdout/stderr、失败退出码及超时仍正常记录；不使用 pythonw、不修改 ComfyUI 安装或第三方节点，不写 sitecustomize 或全局环境。

升级后需退出旧桌面并让新版重新启动它托管的 ComfyUI 才生效。**外部手动启动、被桌面接管的 ComfyUI 不会被注入或重启**；有需要请在任务结束后手动停止外部实例，再让桌面启动。显式要求新控制台/独立进程的第三方命令仍尊重其创建标志；不承诺抑制所有任意插件窗口。

本机便携 Python 实测6个子进程均无控制台句柄；真实 ffmpeg 合成短视频、导出PNG及 ffprobe 读取都收到无窗口标志。51项启动器（含真实Electron/Python）、11项Python策略和400项网关回归通过；未执行真实扩散推理。

## 草稿模式跟随原视频（0.1.17）

此前的草稿不会自动改模式或猜测补线；请设置好原视频节点后重新点击“草稿”。已保存的真实画布不会被此更新批量修改。

## 极速草稿（0.1.13 修复）

在视频卡上输入提示词后点击“草稿”，会生成低分辨率 **MP4 视频（含音轨）**，不是单张预览图。文生或首尾帧沿用原卡；分辨率使用约 448 长边，时长按 H3 的 17k+5 帧网格对齐，例如请求 4 秒实际约 4.46 秒。

使用本地 FL2VA INT8、4步 Turbo v1.2、4B + ClipProj，替换之前失配的 T2VA-only 实验工作流。需要对应模型、ClipProj、VideoHelperSuite 与 SageAttention；本轮使用本机已有资源实测，没有下载权重。该实现不承诺旧 FastH3/PDMD/VSA 的速度。升级会备份并精准迁移未修改的旧内置草稿图和注册项；自定义版本保留，可在服务面板查看冲突。

参考：[MiniMax 官方提示词指南](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md)、[本地权重许可](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/LICENSE)。

## Agent 窗口与消息操作（0.1.11）

- 拖动对话窗口标题区域即可移动，位置独立于右下角图标并保存在本机；窗口改变大小时会自动限制在可见范围内。
- 用户消息、AI 回复下方均提供“重新生成”和“删除消息”。删除会移除选中的消息及其后的全部对话，只保留之前的消息；重新生成会确认后使用当前选中模型，从对应用户问题重试，替换该轮及后续对话。不会撤销已发生的画布改动，工具操作可能再次执行。
- 生成或等待工具确认时禁用消息修改，先停止或等待完成。当前会话内可重用原图片；刷新后附件已过期时会提示重新附图。

## 服务面板日志（0.1.12）

- 每行前面的时间为本机接收到日志的时间，格式 `YYYY-MM-DD HH:mm:ss.SSS`；上游已有的时间戳仍保留。
- 默认勾选“自动跟随”，新增日志自动滚到日志框底部，不移动整个页面。
- 向上查看、选择日志文本或取消勾选时暂停；点击“最新日志”即可回到底部并恢复自动跟随。折叠、重新展开或切回服务面板后保留当前跟随状态。
- 面板继续只显示最近 100 条；重启后从本次会话重新记录。此改动不删除既有磁盘日志。

## 安装与首次使用

1. 运行 NSIS 安装器，选择当前用户安装目录。支持桌面快捷方式和 Windows 卸载入口。
2. 首次默认本机地址：画布 `23110`、网关 `23111`、ComfyUI `8188`。桌面专用端口避免与旧浏览器版的 `3000/8190` 混用。
3. 在「服务面板 → 桌面设置」填写 ComfyUI 地址；需要自动启动时，用原生目录选择器指定 ComfyUI 安装目录。
4. 保存设置后，等待正在进行的任务结束，再点击「重启应用」。未配置目录时只连接 ComfyUI，不扫描硬盘并擅自启动其他安装。
5. 即使 ComfyUI 尚未运行，内置画布和网关仍可打开；生成会如实显示后端不可用。
6. 桌面端启动 ComfyUI 时默认添加 `--disable-auto-launch`，不自动打开系统浏览器；需要查看时使用顶部「ComfyUI」入口。标准便携版脚本保留原启动选项后直接启动其 Python，不改原 BAT。复杂整合脚本若无法安全解析则不自动执行，请手动启动 ComfyUI 后连接。

正式桌面模式只接受明确配置的本机 HTTP 根地址。网关不再自动扫描其他 ComfyUI 端口并切换实例。非桌面版网关占用桌面端口时拒绝接管，避免把安装版策略误套到旧网关；请在桌面设置调整端口，或由服务所有者停止旧服务。

## 程序资源与用户数据

```text
安装目录/
├─ ComfyCanvas.exe           # Electron 与内嵌 Node，无需外部 Node
└─ resources/
   ├─ app.asar              # 桌面主进程、preload、服务面板
   └─ runtime/              # 只读发布资源
      ├─ runtime-manifest.json
      ├─ DEPENDENCY-LICENSES.txt
      ├─ launcher/
      ├─ infinite-canvas/web/dist/
      └─ comfyui-gateway/
         ├─ src/ + node_modules/
         ├─ workflows/ + prompts/ + scripts/
         ├─ comfyui-bridge/
         └─ resources/      # 资源索引、节点源码、小型预览资产
```

用户数据由 Electron 的 `app.getPath('userData')` 管理，Windows 通常位于 `%APPDATA%` 下应用专属目录；具体路径在设置面板展示，提供「打开数据目录」按钮：

```text
用户数据/
├─ config.json             # 桌面连接设置，不包含源码目录路径
├─ logs/desktop.log
├─ workflows/              # 可修改的工作流副本
├─ workflow-baseline.json  # 默认文件升级判定
├─ gateway/
│  ├─ outputs/             # 生成文件，兼容 /files 下载
│  └─ …                    # 任务、资源缓存、目录配置等
└─ Partitions/…            # Electron 画布项目、媒体及本地存储
```

- 程序安装目录不写配置、工作流或生成结果。卸载默认保留用户数据；升级安装包继续使用同一用户目录。
- 更新内置工作流时，只自动替换未被用户修改的旧默认文件。修改过的文件及自建文件保留；冲突显示在设置面板和日志，**不宣称注册表已完成逐项智能合并**。
- 画布项目存储在 Electron 的固定分区，和系统浏览器隔离；已有浏览器项目通过 ZIP 导出/导入迁移。
- 存储也绑定画布 origin/端口。更换端口可能看到新的存储空间，并非原数据被删除；建议固定端口、迁移前导出。

## 生命周期和权限

- 每个业务页使用无 preload 的隔离 `WebContentsView`；切换画布、网关和 ComfyUI 不会重载当前画布。
- 仅服务面板主 frame 能调用受限桌面 IPC；业务页面没有 Node.js、文件系统或任意命令执行能力。
- 启用 sandbox、contextIsolation、webSecurity，关闭 nodeIntegration/webview；HTTP 保持 CORS。外链确认后交系统浏览器，本机白名单弹窗使用隔离窗口。
- 保留原生文件选择、Blob 下载与受限剪贴板能力。图像/视频生成和节点安装仍由现有后端负责。
- 桌面端启动 Python 时固定 UTF-8、无缓冲输出，并捕获标准输出、错误输出及退出码，避免中文 Windows 隐藏进程因 GBK 无法输出 emoji 而启动失败。
- ComfyUI 在就绪前异常退出或等待超时，不再让画布和网关一起退出：继续提供画布/管理页，ComfyUI 标记为未就绪。生成仍需后端恢复；日志展示真实错误，不会自动结束外部实例。
- 桌面自己启动的 launcher、网关和 ComfyUI 才登记为自有进程；退出只清理这些进程。Windows 当前使用自有进程树停止，可能中断其工作，退出前会提示确认并检查已知任务状态。
- 桌面隔离旧浏览器的 open/heartbeat/close 会话流量，避免关闭窗口触发旧 watchdog。外部服务仍可被其原所有者关闭，桌面不保证它们永久运行。
- 设置 ComfyUI 目录后，原网关可能写入工作流桥接扩展；资源中心安装也会写用户选择的 ComfyUI 节点、模型和 Python 环境。这是明确管理操作范围，**不是安装目录之外绝不写盘的沙箱承诺**。

## 发布范围与限制

已包含：画布、网关生产依赖、工作流、提示词模板、必要脚本、内置节点源码及许可、TAEH3 预览 VAE 和节点所需小型 embedding。

不包含：ComfyUI/Python 主程序、数 GB 的生成模型、LoRA/H3 ONNX 大文件。资源中心按需下载，因此不宣称离线全功能。

**禁用源码修复助手与旧补丁更新。** 安装版不再允许网页更新器修改源码/安装目录，助手插件不注册；升级通过新桌面安装包完成。自动更新服务器尚未配置。

**代码签名是发布前独立步骤。** 未提供签名证书时产物为未签名安装包，Windows SmartScreen 可能提示未知发布者。可以在受保护的发布环境提供 `CSC_LINK` / `WIN_CSC_LINK` 及密码给 electron-builder；不要把证书或密码提交到仓库。本工程不绕过 SmartScreen，不伪造签名。

## 测试与发布检查

```powershell
npm run check
npm test
npm run test:smoke
npm run test:integration
npm run pack
npm run test:packaged
npm run dist:win
```

- `test:integration`：真实 Electron + 现有画布 + 真实网关，ComfyUI 使用测试接口；验证复用与自有启动、视图保留、下载、POST 转发及重定向边界。
- `test:packaged`：复制打包应用到临时路径、清空 PATH 中的 Node/npm，从非仓库目录启动；验证读取随包资源、用户目录写入、原安装资源哈希不变、服务退出及外部 ComfyUI 保留。测试产生的画布和配置在临时目录，结果截图保留在被 Git 忽略的测试产物目录。
- `test:live`：只连接已运行的旧开发环境，不启动真实后端，是兼容性检查而非安装版发布验收。
- 共享画布类型检查：在其目录执行 `node node_modules/typescript/bin/tsc --noEmit --incremental false`。
- 后端发行策略与启动器回归：仓库根目录执行 `node --test comfyui-gateway/test/desktop-distribution.test.js launcher/test/desktop-mode.test.js`。

测试不提交真实 GPU 生成任务。真实模型生成、所有插件/剪贴板组合、签名证书和跨机器安装升级仍应在正式公开发行前验收。只有 Windows x64 为本轮打包目标，未验证 macOS/Linux 安装产物。
